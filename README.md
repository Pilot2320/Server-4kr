# Контрольная работа №4. Технологии разработки серверных приложений

Данный репозиторий содержит решение заданий 9.1 и 10.1 по дисциплине «Технологии разработки серверных приложений».

## Структура проекта

*   **Task_9_1/** — Реализация миграций базы данных с использованием Alembic в FastAPI.
*   **Task_10_1/** — Реализация пользовательской обработки ошибок в FastAPI.

---

## Задание 9.1: Миграции базы данных с Alembic

В данном разделе продемонстрирована работа с Alembic для управления схемой базы данных.

### Особенности реализации:
*   Использование **SQLAlchemy** для определения моделей.
*   Настройка **Alembic** для автоматической генерации миграций (`autogenerate`).
*   Создание таблицы `products` с полями: `id`, `title`, `price`, `count`.
*   Добавление поля `description` (NOT NULL) через вторую миграцию.

### Как запустить:
1. Перейдите в директорию: `cd Task_9_1`
2. Установите зависимости: `pip install -r requirements.txt`
3. Примените миграции: `alembic upgrade head`
4. Запустите сидирование данных: `python seed.py`
5. Запустите приложение: `python main.py`

---

## Задание 10.1: Пользовательская обработка ошибок

В данном разделе реализована система обработки исключений для предоставления понятных ответов API.

### Особенности реализации:
*   Пользовательские классы исключений: `ItemNotFoundException`, `InsufficientPermissionsException`.
*   Глобальные обработчики исключений через `@app.exception_handler`.
*   Унифицированные модели ответов об ошибках с использованием **Pydantic**.
*   Тестирование с использованием `TestClient`.

### Как запустить:
1. Перейдите в директорию: `cd Task_10_1`
2. Запустите приложение: `python main.py`
3. Для запуска тестов выполните: `python test_main.py`
